# 🛵 BH Entrega

Um MVP (Produto Viável Mínimo) de plataforma de entregas urbanas focada em Belo Horizonte, inspirada no modelo do iFood/Loggi.

## 🚀 Funcionalidades
- **Multi-perfil:** Login separado para Cliente, Entregador e Administrador (Master).
- **Cálculo de Frete:** Algoritmo baseado em distância (Haversine), peso, volume e tipo de veículo.
- **Rastreamento:** Simulação de mapa em tempo real com Leaflet (OpenStreetMap).
- **Pagamentos:** Fluxo simulado de Pix (com QR Code ilustrativo) e Cartão.
- **PWA:** Funciona offline e pode ser instalado no celular/desktop.

## 🛠️ Tecnologias
- HTML5, CSS3, JavaScript (Vanilla)
- Leaflet.js (Mapas)
- LocalStorage (Banco de dados local para MVP)

##  Como testar
1. Clone o repositório.
2. Abra o `index.html` usando o **Live Server** do VS Code.
3. Use as credenciais de demonstração na tela de login.
